複数入力枠の自動即時判定 ＆ キャッシュ data-nano-judgement

data-nano-judgement 属性を持つ入力枠に 5文字以上 入力されると、Language Detector API と Translator API で即座に英語へ事前翻訳・キャッシュされ、裏で自動的に判定が開始されます。
・2秒以内の再更新: 英語に都度翻訳し、先ほどの文章とは別キーで安全にキャッシュ。
・2秒経過後の更新: 最初の文章から 25%以上テキストが変化した場合、進行中の判定を即座に中断して最新の内容で再判定を開始します。

Webページへの組み込み仕様

入力枠に data-nano-judgement 属性を付与するだけで、JS読み込み時に初期テキストがあれば自動判定・キャッシュが行われます。

<!-- 1. スクリプトの読み込み --> <script src="./nano-judgement.global.js"></script> <!-- 2. 入力枠に属性を付与（セレクトボックス連動例） --> <select id="prioritySelect"> <option value="high" data-description="即時対応必須">高</option> <option value="low" data-description="後回し可能">低</option> </select> <textarea data-nano-judgement data-judge-select="#prioritySelect" data-judge-target="#result-container" >サーバーがダウンしたため緊急対応を求む</textarea> <!-- 3. 判定結果の出力先（任意） --> <div id="result-container"></div> <!-- 入力テキストに応じて、AIがセレクトボックスの選択肢を自動選択（Auto-select）します -->
